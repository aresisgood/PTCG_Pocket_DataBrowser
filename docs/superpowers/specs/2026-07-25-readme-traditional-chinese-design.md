# README 繁體中文化設計

## 目標

將 `README.md` 改寫為以台灣求職閱讀情境為主的繁體中文版本，同時保留 Python 後端工程與資料工程職缺常用的英文技術名詞，讓內容易讀且具技術辨識度。

## 翻譯範圍

- 翻譯專案摘要、特色、章節標題、操作說明、API 用途、資料與模型說明、限制。
- 修正 `Pok矇mon` 錯碼為 `Pokémon`。
- Mermaid 圖的流程動作以中文為主，元件與技術名稱保留英文。
- API 路徑、指令、網址、檔案路徑、環境變數與程式碼區塊維持原值。

## 技術名詞原則

保留 `Python`、`FastAPI`、`SQLModel`、`ETL`、`API`、`Docker`、`SQLite`、`GitHub Actions`、`pytest`、`ML` 等英文名稱。必要時在中文敘述中補充用途，但不創造新的功能或支援範圍。

## 內容誠信

- 保留既有 AUC、log-loss 與未見對戰覆蓋率數字及其限制。
- 明確維持 SQLite 是已驗證資料庫的說明。
- 保留 Docker 尚未在本機實際建置與執行驗證的揭露。
- 不宣稱公開部署、PostgreSQL 支援、正式環境可用性或保證性的模型表現。

## 驗收標準

- README 的一般敘述與表格用途欄均為繁體中文。
- 技術指令、API 路徑與環境設定未被翻譯或改寫。
- Mermaid 語法可由 GitHub 正常解析。
- 不殘留 `Pok矇mon`、未完成標記或與程式不符的宣稱。
- 文件更新通過 `git diff --check`，並更新既有 PR #4。
